## 数据格式

作者作品集（`唐/李白.json`）：

```json
{
  "dynasty": "唐",
  "author": "李白",
  "author_desc": "…小传…",
  "works": [
    {
      "title": "静夜思",
      "paragraphs": ["床前明月光，", "疑是地上霜。", "举头望明月，", "低头思故乡。"],
      "annotations": [
        {
          "notes": ["床——…", "疑——…"],
          "translation": "…",
          "appreciation": "…"
        }
      ]
    }
  ]
}
```

典籍单行本（`先秦/论语.json`）：

```json
{
  "title": "论语",
  "dynasty": "春秋",
  "author": "孔子弟子及再传弟子",
  "chapters": [
    {"chapter": "学而篇", "paragraphs": ["…"], "annotations": []}
  ]
}
```

- `dynasty` 为具体朝代（北宋/南宋/春秋/战国/东汉…），目录为大朝代分区
- `annotations` 为释义数组（注释/译文/赏析）
